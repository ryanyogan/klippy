- One new file, .mcp.json, with three "type": "http" servers.

## Review checklist
- [ ] Exactly three servers, all https, all from the providers' own docs.
- [ ] `git diff` shows no key, token or account id. `${FIRECRAWL_API_KEY:-}` is fine; a real `fc-…` key is a reject.
- [ ] Reject: a server you didn't ask for, a local `command` that runs code from an unknown package, or user scope
      (it wouldn't be in the repo).
