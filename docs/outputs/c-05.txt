# @cloudflare/ai-chat 0.12.2, ai 7.0.162, zod 4.6.7.
# MODEL: no Anthropic key on the gateway, so the Workers AI fallback (@cf/zai-org/glm-4.7-flash) answered.
#
# Notes for the writer:
# - What changed: src/tools/memory.ts (facts(), remember, forget: a `facts` table in the agent's own SQLite through
#   this.sql, created on first use); src/agent.ts builds the system prompt per turn with "What you know about the user
#   (id: fact)" and adds the two tools; scripts/chat.ts gets "/clear" (sends CF_AGENT_CHAT_CLEAR, MessageType from
#   @cloudflare/ai-chat/types), so the recording can show memory outliving the chat history; test/memory.spec.ts.
# - Short vs long-term memory: the chat history (c-03/c-04) is short-term and capped at 40 messages; facts are
#   long-term, survive /clear, and cost a few tokens each turn because they ride in the system prompt.
# - Caps (budget rules): 50 facts of up to 200 characters (zod .max on the input, a refusal result at 50), so the system
#   prompt stays small. The facts are read fresh every turn.
# - Security, for c-06: remember/forget are writes the model makes on its own. Once readLink comes back (c-06), a page
#   could try to plant a "fact" (memory poisoning), so the prepareStep cut drops remember and forget along with the
#   notes tools after a page read.
# - The model's id in "forget" comes from the system prompt list; the fallback model found it without help here.
