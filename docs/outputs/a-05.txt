# NOTES FOR THE WRITER (security review, 2026-11-03), teach these in A5, before the first deploy:
# - Deploying makes /ask public, and every call spends the learner's own Anthropic key (denial of wallet).
# - Lock 1, only you: /ask needs 'Authorization: Bearer <KLIPPY_TOKEN>'. The token is a Worker secret
#   (wrangler secret put; .dev.vars locally), declared in wrangler.jsonc under secrets.required so wrangler types
#   types it and wrangler dev warns when it's missing. No token set means the door stays shut (401).
#   The comparison hashes both sides and uses crypto.subtle.timingSafeEqual, so response timing leaks nothing.
# - Lock 2, not too often: the Workers Rate Limiting binding (ratelimits, LIMITER) allows 10 model calls a minute
#   per client address on /ask. Over: 429. The binding's counters are per Cloudflare location and approximate:
#   a brake, not a bill cap.
# - /klippy/check must stay public (bits calls it), and anyone can call it, not only bits: bits' own limits don't
#   protect the learner's key. So the probe answer is the same for every caller and is cached in a module-level
#   memo for 5 minutes (the second check in the recording answers in 7 ms with the same probe and a fresh nonce),
#   and a fresh probe (a cache miss) also needs the rate limiter under ONE shared key, 'check': at most 10 model
#   calls a minute in total, whoever asks. The limiter guards only the miss, so a flood of callers can't block
#   bits from getting the cached answer. The memo lives per isolate (Workers may run several), which is why the
#   shared rate-limit key is the real cap. The test proves two checks make exactly one model call.
# - The real bill cap lives at the gateway: AI Gateway rate limiting (requests) and spend limits (dollars, BYOK too),
#   per gateway: developers.cloudflare.com/ai-gateway/features/{rate-limiting,spend-limits}/ (checked 2026-11-03). Course F (F2/F3) goes deeper; A5 should point there.
# - The check route accepts only an 8-64 character [A-Za-z0-9_-] nonce, so it never echoes arbitrary input,
#   answers no-store, and asks a fixed question (capped by maxOutputTokens: 300, from a-04).
# - TAG in src/check.ts is bumped at each course checkpoint (a-05, b-09, c-09, ...), not at every tag.
# - Observability: logs and traces are on in wrangler.jsonc (traces start counting toward Observability
#   pricing on 2026-12-01, per developers.cloudflare.com/workers/observability/traces/, checked 2026-11-03).
