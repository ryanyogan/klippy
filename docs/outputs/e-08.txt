# Notes for the writer:
# - What changed:
#     apps/agent/test/eval/corpus.ts          6 made-up documents (our own text) and 12 questions, each with the
#                                             document that answers it. Learners replace them with their own
#     apps/agent/test/eval/recall.ts          recallAt(k, results, answers)
#     apps/agent/test/eval/retrieval.eval.ts  ingests the corpus under a fresh owner (eval-<time>): chunk, save, embed,
#                                             upsert; waits for Vectorize to see them; then for each question records the
#                                             top-5 titles from keywords only, vectors only, hybrid, hybrid + rerank;
#                                             prints recall@5 (and recall@1 for the reranked list) and each question's top
#                                             hit; deletes its vectors at the end; fails under 0.75
#     apps/agent/vitest.eval.config.mts       same as vitest.config.mts but remoteBindings: true and only *.eval.ts
#     apps/agent/package.json                 "eval:retrieval": "vitest run --config vitest.eval.config.mts"
#     apps/agent/test/recall.spec.ts          a unit test for recallAt, so CI covers the arithmetic
# - This is a measurement, not a test: it calls the real Workers AI embedding model and reranker and the real Vectorize
#   index (`wrangler login` needed), costs a few cents' worth of calls at most, and is not in `pnpm test` or CI. No chat
#   model is called (no contextual step: the numbers are the base pipeline).
# - Honest reading of the numbers below: this corpus is too easy. Every method finds every answer in its top 5, so
#   recall@5 can't tell them apart; recall@1 (0.92) shows the one miss ("undo a bad release" -> the rollback line is in
#   work-notes.md, but the reranker put bike.md first). The lesson's point: measure on YOUR questions, make the set
#   harder (paraphrases, exact codes like TP1337, near-duplicates) until the methods differ, then tune. Anthropic's
#   "Demystifying evals for AI agents" is the source for "measure before tuning".
# - --reporter=verbose shows the printed report; vitest's default reporter hides console output of passing tests here.
