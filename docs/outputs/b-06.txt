# b-06 Choosing when Claude calls. Recorded 2026-11-03 on Linux, Node v24.22.2, wrangler 4.157.0, agents 0.33.0, ai 7.0.162, zod 4.6.7, remix 3.1.0.
# MODEL: no Anthropic key on the gateway, so the Workers AI fallback (@cf/zai-org/glm-4.7-flash) answered both routes.
# Notes for the writer:
# - New here: POST /note (src/note.ts) forces one tool: toolChoice: { type: 'tool', toolName: 'saveNote' }, and
#   stopWhen: isStepCount(1), so the saved note is the reply (one model call, no "done!" turn). /ask now says
#   toolChoice: 'auto' out loud (the default). The /klippy/check probe still sends no tools at all.
# - AI SDK -> Claude API names: 'auto' = auto, 'required' = any, { type: 'tool', toolName } = tool, 'none' = none.
#   'none' keeps the tool definitions in the prompt but forbids calls; sending no tools is stronger, which is why the
#   public check route sends {}.
# - Claude docs (platform.claude.com, define-tools, "Forcing tool use", checked 2026-11-03): Claude Haiku 5.5 accepts
#   forced tool use, but a forced call skips thinking (the reply starts with the tool call). Claude Opus 5.5, Sonnet 5.5,
#   Fable 5.1 and Mythos 5.1 REJECT any/tool with a 400; use auto + strict tool use, or structured outputs, there.
#   Manual extended thinking also rejects any/tool. Say this in the lesson: forcing is model-dependent.
# - The recording shows what forcing means: "what is 2+2?" sent to /note was saved as a note, not answered.
# - Security: /note is a new route that spends model and D1 budget, so it shares /ask's locks through guardedText()
#   in src/index.ts: the bearer token, the rate limit (one shared budget of 10 a minute per address), and a 1..2,000
#   character string field. A note over 1,000 characters fails the tool's schema and the route answers 422 (a test).
# - The 429 text changed from "Too many questions" to "Too many requests" (shared by both routes).
