#        is corrected. f-04 corrected with "?? 0", which refunded the whole reserve when the count was missing.
#     4. Same day: reserve() returns { day, tokens } and settle() corrects THAT day's row, so a turn that crosses
#        midnight UTC doesn't refund the new day.
