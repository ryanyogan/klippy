# Notes for the writer:
# - The plan says onStepFinish; in ai 7.0.162 onStepFinish is a deprecated alias of onStepEnd. Teach onStepEnd.
# - The two JSON lines in Terminal 1 are the round trip: step 0 ends with finish "tool-calls" (the model asked for
#   getWeather; the SDK ran it and recorded toolResults), step 1 ends with "stop" (the answer). generateText's text is
#   the last step's text only, so step 0's "I'll get the weather..." never reaches the reply.
# - tokens grows from step 0 to step 1 because step 1 re-sends the conversation plus the tool result.
