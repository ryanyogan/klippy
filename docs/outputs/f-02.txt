# - FACT CHECKED (AI Gateway caching docs, 2026-11-03, maxAge 0): caching is OFF by default; cf-aig-cache-ttl only sets the
#   lifetime "for a request that already uses caching"; cf-aig-cache-key is what opts one request in; TTL minimum 60 s,
#   maximum one month; the default key is an exact hash of provider, endpoint, model, auth header and the full body.
#   So the plan's createAI({ cacheTtl }) ALONE caches nothing on a fresh gateway: the lesson must use cacheKey too (or
#   turn on caching in the gateway settings). That's why Klippy sets both.
# - Why only the probe is cached: a chat is personal and time-dependent (getTime, your notes). A cached chat reply could
#   answer Bob with Alice's words if the key were wrong. Cache only what's the same for everyone.
# - Metadata is labels only (app, route, user id): never the question, a note or a token. Teach that the gateway LOG
#   itself stores prompts and replies by default (collectLog); for a personal Klippy that's your own data in your account.
# - Spend control (dashboard, not code): AI Gateway spend limits (changelog 2026-06-05, checked today) are cost budgets
#   that block requests once spent, scoped by model, provider or custom metadata, so the "user" label above is what a
#   per-user daily dollar limit keys on. The account-wide Budget alerts (Billing, changelog 2026-04-13) email you, but
#   fire the day after. NOT SET on the recording account: owner checklist.
