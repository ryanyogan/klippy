# MODEL: the 'default' gateway on the recording account has no Anthropic key stored (no BYOK), so the Claude call

#
# NOTES FOR THE WRITER (security review, 2026-11-03), teach these in A4:
# - Never trust the body. /ask checks at runtime that question is a string, trims it, and refuses blank or
#   over-2,000-character questions with a 400. TypeScript's <{ question?: unknown }> is only a hint; it checks nothing.
#   The question goes in as messages: [{ role: 'user', content }], not spliced into a prompt string.
# - Denial of wallet: every /ask spends the learner's own key. maxOutputTokens: 300 caps each reply and the length
#   cap bounds each input. Locally that's enough; a-05 adds a guard before the first deploy makes /ask public.
# - The tests prove the 400s and that the cap reaches the model call (doGenerateCalls on the fake model).
